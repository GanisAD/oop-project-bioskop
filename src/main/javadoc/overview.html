Dokumentasi API Cinema XXI - Sistem Pemesanan & Manajemen Bioskop, aplikasi desktop berbasis JavaFX untuk mata kuliah Pemrograman Berorientasi Objek.

Struktur package mengikuti pola MVC:

  • model.* - data dan logika bisnis (bioskop, tiket, pengguna)
  • controller - penghubung antara tampilan FXML dan model
  • app - titik masuk dan data bersama aplikasi
